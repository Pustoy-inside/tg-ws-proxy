# TG WS Proxy для iOS — изменения

## Сборка 4

Всё из сборки 3 плюс обход на мобильном интернете.

- В «Настройке обхода» появился раздел «Мобильный интернет»: выбираешь оператора (МТС, МегаФон, Билайн, Т2, Yota, Т-Мобайл, СберМобайл) или вписываешь свой APN, и приложение выдаёт профиль сотовой сети с прокси 127.0.0.1.
- Пока приложение не запущено, сайты на мобильном интернете не открываются: у сотовой сети в iOS нет запасного пути «напрямую». Профиль удаляется в Настройки → Основные → VPN и управление устройством.

## Сборка 3

Обход блокировок YouTube и Discord по идеям zapret-discord-youtube, работает одновременно с прокси для Telegram.

- Локальный HTTP-прокси на 127.0.0.1:8881. Для доменов из списков zapret (YouTube, Discord, Cloudflare — 73 домена) первый пакет соединения отправляется с обходом DPI, остальные сайты идут без изменений.
- Способы обхода на выбор: фрагментация TLS + разбивка (по умолчанию), фрагментация TLS + перестановка, разбивка по SNI, перестановка (disorder), OOB-байт, только фрагментация TLS.
- Подключение на Wi-Fi через автоматическую настройку прокси (PAC): `http://127.0.0.1:8881/proxy.pac`. Если приложение выключено, сайты открываются напрямую.
- Свои домены, режим «для всех сайтов», статистика и строки в журнале, если способ не сработал.
- Не поддерживается: голос в Discord (UDP) и фейковые пакеты из стратегий FAKE — на iOS без VPN их не отправить.

## Сборка 2

- Прокси больше не использует VPN: бесплатный Apple ID не может подписать VPN-модуль, из-за этого в сборке 1 был отказ «permission denied». Теперь прокси работает внутри самого приложения.
- Чтобы iOS не усыпляла приложение, пока открыт Telegram, есть два способа на выбор: грубая геолокация (по умолчанию, в строке состояния видна синяя стрелка) или тихий звук, который не мешает другим звукам.
- Настройка «Включать при запуске приложения»: если iOS закроет приложение, прокси включится сам при следующем открытии.

## Сборка 1

Первая версия порта tg-ws-proxy на iPhone и iPad.

- Прокси MTProto на `127.0.0.1:1443`, как в оригинале: Telegram подключается к нему, а прокси несёт трафик к дата-центрам Telegram через WebSocket (`kwsN.web.telegram.org`).
- Запас готовых соединений к DC (по умолчанию 4), обход через фронтинг SNI, если прямое соединение не проходит.
- Запасные пути, как в оригинале: Cloudflare Worker (свои домены), CF-прокси (встроенный список доменов с обновлением раз в час) и прямое TCP-соединение.
- VPN-модуль держит прокси запущенным, когда открыт Telegram. Трафик телефона через VPN не идёт.
- Кнопка «Добавить прокси в Telegram», статистика соединений и трафика, журнал с кнопкой «Поделиться».
- Настройки: порт, секрет, IP дата-центров, запас соединений, домены Cloudflare, автоматическое включение, подробный журнал.
