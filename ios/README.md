# TG WS Proxy для iOS

Порт [tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy) на iPhone и iPad: локальный MTProto-прокси, который ускоряет Telegram, передавая его трафик через WebSocket.

## Установка

1. Скачай `TGWSProxy-N.ipa` из [Releases](../../releases).
2. Поставь его через iloader или SideStore.
3. Открой приложение и включи «Прокси для Telegram». Разреши доступ к геолокации «При использовании».
4. Нажми «Добавить прокси в Telegram» и включи прокси в Telegram.

Прокси работает внутри приложения. Бесплатный Apple ID не может подписать VPN-модуль, поэтому в фоне приложение держится за счёт грубой геолокации или тихого звука (выбирается на главном экране). Не закрывай приложение смахиванием из списка недавних.

## Как это устроено

- `ios/Engine` — перенос логики из `proxy/` на Swift: расшифровка рукопожатия, новое шифрование к Telegram, WebSocket-клиент, пул соединений, запасные пути.
- `ios/App` — приложение: запуск прокси, работа в фоне, настройки, журнал.

## Сборка

Сборку запускает изменение `ios/build.json` в `main` (или вручную, workflow «iOS IPA»). IPA появляется в Releases с тегом `ios-build-N`, список изменений берётся из `CHANGELOG-iOS.md`.
